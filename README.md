# Sarvan C — AI/ML & Software Engineering Portfolio

A multi-page portfolio built with React, TypeScript, Vite, and TanStack Start.

## Requirements

- Node.js 20 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Pages

- `/` — Home
- `/about` — About
- `/skills` — Skills
- `/projects` — Featured projects
- `/experience` — Experience and education
- `/blog` — Writing drafts
- `/contact` — Contact details

The downloadable resume is stored at `public/resume.pdf` and linked from the navigation bar and home page.
